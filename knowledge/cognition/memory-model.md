# Memory Model

## Why

A language model has perfect recall of everything in its context. Human
memory does not. It is reconstructive, semantic, emotionally distorted, and
full of holes — and the holes have causes. When narration quotes a
three-week-old conversation verbatim, or recalls a room in photographic
detail, it betrays the model behind the character.

## Memory fidelity levels

| Level | Meaning | When justified |
|---|---|---|
| exact | Verbatim recall | Traumatic imprint, rehearsed lines, professional training, very recent |
| semantic | Meaning retained, wording lost | The default for conversation and events |
| partial | Fragments: an image, a phrase, a feeling | Normal long-term recall |
| fuzzy | Gist with low confidence | Old, unimportant, or poorly attended events |
| uncertain | Explicitly flagged as unreliable | "He thought it had been raining, but..." |
| misremembered | Wrong, with a plausible cause | See causes below |
| emotionally_distorted | Reshaped by feeling | Shame softens, anger sharpens, grief edits |
| forgotten | Gone | Never attended, never consolidated, or decayed |
| suppressed | Actively unrecalled | Guilt, trauma, social cost — with avoidance behavior |

## Rules

1. **Semantic over verbatim, by default.** A character may remember *what
   happened* without remembering *the exact sentence spoken*. The writer must
   not manufacture perfect quotations from distant memories unless exact
   recall is justified.
2. **Misremembering needs a cause.** Emotional distortion, time, stress,
   lack of attention, incomplete observation, conflation of similar events,
   ordinary semantic decay. Never random error as a stylistic trick. Before
   accepting a misremembering, ask: *why would this character remember it
   wrong?*
3. **STORY MEMORY ≠ CHARACTER MEMORY.** The archive/canon system retains
   story truth. The cognition system models what the character *believes*
   happened. A character may remember an event incorrectly while the
   timeline stays correct. Cognitive imperfection must never be used to
   change established facts, break chronology, or contradict locked canon —
   that is a canon error, not a character misunderstanding. Only the second
   is allowed.
4. **Uncertainty is allowed on the page.** "He couldn't remember whether..."
   is a valid narrative state. Not every memory needs to resolve.

## Memory and attention interact

What was never attended is never encoded. If the attention model says an
element was PERIPHERAL or IGNORED in the original scene, later recall of it
in detail is an epistemic violation — unless the character has since
re-encountered or reconstructed it (which itself should be shown or marked).
